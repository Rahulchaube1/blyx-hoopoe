# Hoopoe starter

Plan a thumbnail and check the decoded pixel buffer against a byte budget.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Hoopoe** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
100
50
300
15000
0
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/hoopoe) · [View the release](https://github.com/Rahulchaube1/blyx-hoopoe/releases/tag/v0.1.0)
